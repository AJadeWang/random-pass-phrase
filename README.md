# Secure Passphrase Generator

A zero-data-storage passphrase generator built with vanilla HTML, JavaScript, and CSS for a single lightweight web app deployed to Firebase Hosting.

## Features

- 🔐 Generates secure, memorable passphrases
- 🚀 No data stored anywhere
- 📱 Mobile-responsive design
- 🎨 Modern, clean UI
- ⚡ Instant generation
- 📋 Copy to clipboard

## Technical Stack

- Firebase Hosting
- Vanilla JavaScript, HTML, and CSS

## Deployment

1. Fork this repository
2. Set up Firebase project
3. Add FIREBASE_TOKEN as GitHub secret
4. Push to main branch
